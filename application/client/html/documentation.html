Application Documentation

Description

This application is designed for employees of a shoe store. It allows them to create customer orders and consult previously stored orders.

Authentication

Employees must log in using their username and password before accessing the application operations.

Available Operations

  • Create a new customer order.
  • View all stored orders.
  • Search for a specific order using its ID.

Creating Orders

To create an order, employees must enter the order ID and the customer's personal information. They can select products and their quantities.

The application calculates the subtotal, adds 21% VAT and calculates the final price.

Order Storage

Orders are stored permanently in a JSON file called orders.json. The information can be consulted later using the order viewing options.

Technologies Used

  • HTML and CSS for the user interface.
  • JavaScript for form validation and communication.
  • PHP for server-side operations.
  • JSON for permanent data storage.
  • Apache with HTTPS support.
